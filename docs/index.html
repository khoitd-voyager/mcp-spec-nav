02 / Connect your agent

A small config.
A better starting point.

Use Node.js 18+, npm/npx, Git, and a local checkout of the repository you want to scan.

  1. Add this config to .mcp.json in your target repository.
  2. Replace SPEC_NAV_ROOT with the absolute path to your codebase.
  3. Restart Claude Code, run /mcp, and check that spec-nav is connected.
Prefer Claude Desktop? Install the extension ↗
.mcp.json
{
  "mcpServers": {
    "spec-nav": {
      "command": "npx",
      "args": [
        "-y",
        "github:khoitd-voyager/mcp-spec-nav"
      ],
      "env": {
        "SPEC_NAV_ROOT": "/absolute/path/to/your-repo"
      }
    }
  }
}
Use your monorepo root to cover multiple services.

Live run: Claude Code (Claude Sonnet 5.5) on 8 Grafana PRs, plain vs. a spec-nav setup that is not the MCP alone: MCP + instructions + a hook that forces spec-nav calls. Both passed every hidden test; quality differences were within noise and the forced setup cost about 58% more per session. The MCP alone has not been measured yet. The other benchmarks use deterministic agent policies with estimated token counts. Read the methodology and limitations before quoting results.
