## Build and test

To run your local build in a client, see [Install from a local checkout](installation.md#install-from-a-local-checkout).

```bash
npm install
npm run typecheck
npm test
```

`npm test` builds the bundle and tests it through MCP stdio on fixture repositories.

These checks validate the tested scenarios. They do not establish that an agent will produce better code on every task. See the [benchmark](../../bench/README.md#english) for with/without-MCP measurements, and run `bench/real.mjs` on your own repository.

## Package the Claude Desktop extension

```bash
npm run pack:mcpb
```

This builds `dist/index.cjs`, stages it under `build/mcpb/` with `manifest.json`, `web-tree-sitter` and only the grammar `.wasm` files, validates the manifest and writes `build/mcp-spec-nav-<version>.mcpb`. The manifest is generated by [scripts/pack-mcpb.mjs](../../scripts/pack-mcpb.mjs); its version comes from `package.json`. To publish, attach the `.mcpb` file to a GitHub release.

To run the tests against the packed extension instead of `dist/`:

```bash
unzip -q build/mcp-spec-nav-<version>.mcpb -d /tmp/spec-nav-mcpb
SPEC_NAV_DIST=/tmp/spec-nav-mcpb/dist/index.cjs node --test test/*.test.mjs
```

## Benchmarks

```bash
npm run bench                                   # synthetic: 100 + 50 large sessions
node bench/real.mjs --repo /path/to/your/repo   # your own repository, oracle-checked
node bench/perf.mjs --repo /path/to/huge/repo   # timings and memory
node bench/flow.mjs                             # cross-service flow links, held-out seeds
```

Options, method and limitations: [bench/README.md](../../bench/README.md#english).

## Website

The GitHub Pages site lives in `docs/` (`index.html`, `vi/`, `zh/`). Edit `docs/index.html`, then regenerate the localized pages with `python scripts/build-pages.py`. See [GITHUB-PAGES-SETUP.md](../../GITHUB-PAGES-SETUP.md).
